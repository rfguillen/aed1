# Etapa 300 · Índice de palabras con trie

Combina una tabla hash de páginas con un árbol trie que relaciona cada palabra normalizada con las páginas que la contienen. Implementa consultas por URL y por palabra.

## Archivos

ArbolTrie y NodoTrie, además de los módulos de la etapa anterior.

## Compilación y ejecución

Desde esta carpeta, con un compilador C++ disponible y Make:

```bash
make
./a.out
```

El programa recibe los datos por la entrada estándar.
