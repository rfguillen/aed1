# Etapa 200 · Diccionario con tabla hash

Incorpora las clases Pagina y TablaHash para gestionar las páginas. Mantiene el intérprete y la normalización del contenido, y permite consultar páginas por URL.

## Archivos

main.cpp, Pagina, TablaHash, Diccionario, Interprete y Normalizar.

## Compilación y ejecución

Desde esta carpeta, con un compilador C++ disponible y Make:

```bash
make
./a.out
```

El programa recibe los datos por la entrada estándar.
