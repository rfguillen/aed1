# Etapa 002 · Normalización de texto

Transforma las letras mayúsculas en minúsculas y normaliza las vocales españolas acentuadas y la ü. La ñ se conserva. Muestra cada palabra original junto a su versión normalizada.

## Archivos

002.cpp.

## Compilación y ejecución

Desde esta carpeta, con un compilador C++ disponible:

```bash
g++ -std=c++11 002.cpp -o normalizar
./normalizar
```

El programa recibe los datos por la entrada estándar.
