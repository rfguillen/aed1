# Etapa 001 · Lectura de palabras

Lee palabras separadas por espacios o saltos de línea y las muestra numeradas, conservando el texto original.

## Archivos

001.cpp.

## Compilación y ejecución

Desde esta carpeta, con un compilador C++ disponible:

```bash
g++ -std=c++11 001.cpp -o palabras
./palabras
```

El programa recibe los datos por la entrada estándar.
