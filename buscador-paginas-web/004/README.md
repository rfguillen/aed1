# Etapa 004 · Diccionario con lista ordenada

Separa el programa en módulos y almacena páginas en una lista ordenada por URL. Permite buscar una URL y actualizar los datos de una página ya registrada.

## Archivos

main.cpp, Diccionario, Interprete y Normalizar.

## Compilación y ejecución

Desde esta carpeta, con un compilador C++ disponible y Make:

```bash
make
./a.out
```

El programa recibe los datos por la entrada estándar.
