# Etapa 003 · Intérprete de órdenes

Introduce el formato de órdenes del buscador y la lectura de páginas con relevancia, URL, título y contenido. Cuenta las palabras recibidas hasta "findepagina".

## Archivos

003.cpp.

## Compilación y ejecución

Desde esta carpeta, con un compilador C++ disponible:

```bash
g++ -std=c++11 003.cpp -o interprete
./interprete
```

El programa recibe los datos por la entrada estándar.
